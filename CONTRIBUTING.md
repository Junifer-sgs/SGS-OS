# Contributing to SGS OS

Thank you for your interest in SGS OS.

## Before contributing

- Open an issue or contact the project owner before beginning substantial work.
- Do not submit code, images, sounds, fonts, or other materials unless you created them or have permission to contribute them.
- Identify any third-party code or assets and provide their source and license.
- Never include passwords, API keys, access tokens, private user data, or other secrets in a contribution.

## Permission and ownership

Submitting a contribution does not automatically transfer ownership of your original work to Junifer. By submitting material, you confirm that you have the right to submit it and that you are willing to discuss and document the permissions needed for SGS OS to use it.

A contribution is not accepted for use in SGS OS until the project owner has explicitly accepted it and the required permissions have been agreed in writing.

Do not assume that contributing to the repository grants you permission to reuse other SGS OS code or assets in your own projects.

## Questions

For contribution questions or permission requests, contact Junifer through the official SGS OS Discord server.
