# Security Policy

## Reporting a security issue

If you believe you have found a security vulnerability in SGS OS, please report it privately to Junifer through the official SGS OS Discord server.

Please do not publish exploit details, access tokens, passwords, private user information, or instructions that could put users at risk in a public issue or public message.

When reporting, include:

- A short description of the issue.
- The affected page, feature, or version.
- Steps to reproduce it in a safe test environment.
- The potential impact.
- Any screenshots or logs that do not expose secrets or personal information.

## Response

The project owner will review the report and may ask for additional information. Please allow reasonable time for investigation and a fix before publicly disclosing details.

## Supported versions

Security fixes are generally focused on the latest version of SGS OS. Older versions may no longer receive updates.
